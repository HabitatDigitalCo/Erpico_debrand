Configuración
=============

El addon no define ajustes propios y mantiene Ventas y Compras como dependencias
obligatorias. Comprobar el impacto funcional de esas dependencias antes de
instalarlo.

Si se requiere prohibir acceso a EDI, definir y probar controles de servidor
independientes. Revisar permisos, tokens y enlaces de portal en cada entorno.
Respaldar base y filestore antes de instalar o actualizar.
